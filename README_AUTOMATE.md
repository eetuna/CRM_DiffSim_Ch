## 🎯 Step-by-Step Workflow

### 1. Initial Setup (ONE-TIME)

Open in DevContainer (VS Code will auto-setup)
Then run:

make setup

text

**What this does (automatically):**
- ✅ Checks CRM code exists
- ✅ Builds CRM libraries if needed
- ✅ Builds C++ Python bindings
- ✅ Installs Python package
- ✅ Creates data/, models/, logs/, results/ directories
- ✅ Generates config.yaml with your settings

**Time: 2-5 minutes**

---

### 2. Generate Training Data

make data

text

**What this does:**
- ✅ Generates kinematics data (50,000 samples)
- ✅ Generates dynamics data (1,000 trajectories)
- ✅ Saves to data/

**Time: 10-30 minutes**

---

### 3. Train All Models

make train

text

**What this does:**
- ✅ Trains kinematics residual model
- ✅ Trains dynamics model
- ✅ Trains RL agent (5,000 episodes)
- ✅ Saves all models to models/
- ✅ Generates training_curves.png

**Time: 2-6 hours**

---

### 4. Evaluate Agent

make evaluate

text

**What this does:**
- ✅ Runs 100 evaluation trials
- ✅ Prints success rate and statistics
- ✅ Generates evaluation_trajectory.png

**Time: 5-10 minutes**

---

### 5. Run Tests (Optional)

make test

text

**What this does:**
- ✅ Runs all pytest tests
- ✅ Generates coverage report (htmlcov/)

**Time: 30 seconds - 2 minutes**

## 🔧 Development Commands

### Build C++ Bindings Only

make build-cpp # Incremental build
make build-cpp --clean # Clean + full rebuild

text

Useful when:
- You modify `crm_bindings.cpp`
- You update your CRM C++ code
- Build fails and needs clean rebuild

### Enable GPU Support

make gpu

text

**What this does:**
- Detects your GPU and CUDA version
- Uninstalls CPU-only PyTorch
- Installs CUDA-enabled PyTorch
- Verifies GPU is accessible
- Shows GPU memory info

**Benefits:**
- 5-20x faster training
- Can use larger batch sizes
- Real-time monitoring: `watch -n 1 nvidia-smi`

### Check System

make check

text

**What this checks:**
- ✅ Python version
- ✅ CMake, g++, Eigen3
- ✅ PyTorch (CPU/GPU)
- ✅ C++ bindings built
- ✅ CRM libraries
- ✅ Project directories
- ✅ GPU info (if available)

Useful for debugging setup issues.

scripts/enable_gpu.sh	Enable GPU support	Have GPU but training is slow (CPU-only)
